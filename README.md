# 🐳 你的机器人 · QQ + B站 AI 角色机器人（通用版）

一只住在 **QQ 群** 和 **B站** 里的 AI 角色：会聊天、会互恼、会自己刷视频发评论、有长期记忆、有性格。

> 设计目标：**一个脑子，多张嘴**。
> 记忆 / 好感 / 心情 / 性格是同一份，QQ 和 B站 只是两张嘴。

---

## ✨ 能干什么

| 能力 | 说明 |
|---|---|
| 💬 **QQ 群聊天** | NapCat / OneBot 11 反向 WS；短句、阴阳、抬杠，人格可换 |
| 🎭 **人格卡** | 一份 Markdown 就是她的性格；每轮自动注入；改完立刻生效 |
| 📚 **长期记忆** | 群聊全量归档 → 自动分段 → 提炼成“谁是谁/发生过什么/踩过的坑” → **每轮自动带着** |
| 🔍 **搜到就记** | 她联网查到的东西写进笔记 → 5 分钟内自动出现在记忆卡上 |
| ✉️ **B站 私信秒回** | 10~20 秒轮询；能翻整个私信会话（含对方发的图片/视频链接） |
| 📺 **B站 主动行为** | 自己刷推荐流、看视频、发评论、回评论/@、发动态、点赞投币关注 |
| 🛡️ **安全** | 只有两条红线：**涉政 ✗ 涉黄 ✗**；其余随便她 |
| 🖥️ **Web 控制台** | 看状态、改配置、看她说过什么 |
| 🧠 **会话体积哨兵** | 快撞模型上限时提前提醒（记忆已外置，清会话也不丢记忆） |

## 📦 目录

```
panel/     server.py + qq.py      面板后端 + NapCat WS 客户端 + 私信秒回
scripts/   history_archive.py     群聊归档（每 5 分钟）
           history_rotate.py      档案到量自动分段
           memory_sync.py         档案 → memory.md（长期记忆）
           memory_digest.py       提炼摘要 → 记忆卡（自动注入）
           session_guard.py       会话体积哨兵
           deep_memory.py         历史回溯 / 随机遗忘
core/      通用内核（人设/好感/心情/记忆/安全/模型）
docs/      人格卡示例 + 配置示例
```

## 🚀 装（Windows）

1. **装 NapCat**（QQ 的 OneBot 实现）：<https://github.com/NapNeko/NapCatQQ> → 扫码登录你的 QQ
2. **装 DSH**（大脑）并写一份 QQ 预设人格
3. 复制 `docs/config.example.json` → `config.json`，填 4 项：
   `SESSDATA` / `bili_jct` / `NapCat accessToken` / `QQ 号`
4. 一键装：
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install.ps1
   ```
5. 打开面板：`python panel\server.py --port 8787` → <http://127.0.0.1:8787>

## ⚙️ 关键设计（为什么她“记得住”又“不会撑爆”）

* **记忆外置**：人格卡里只放 ①谁是谁 ②大事 ③黑话 ④她的坑 ⑤她自己记的笔记（约 850 token）
  → 每轮自动带着，**清会话也不失忆**
* **细节按需读**：完整流水在 `memory/memory.md`，需要时才读 → 不占固定开销
* **归档三段式**：原始档案 → 到量分段 → 提炼记忆卡（每 5 分钟自动跑）
* **红线只有两条**：涉政、涉黄。其余交给模型判断
