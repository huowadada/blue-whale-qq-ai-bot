# dfy-core · 大肥鱼通用版（角色内核 + 平台适配器）

> ★ 设计依据：解析 chenluQwQ/bilibili-ai-bot（MIT）的架构，
> 把它的“角色内核”抽出来，做成**平台无关 / LLM 无关**的通用层。
> ★★ **一个脑子**（记忆/好感/心情/成长全局共享）✓ 不是“第二个她” ✗

## 层次

```
core/          角色内核（不知道对面是 QQ 还是 B 站）
  persona.py     人设 / 多角色 / 提示词模板（含主人提示词）
  memory.py      语义向量记忆 + 永久记忆 + 压缩（按线程/用户分桶）
  affection.py   好感度 0~100 + 关系等级 + 用户档案/印象
  mood.py        心情（影响语气）
  growth.py      每日反思 → 性格演化（特质/口癖/看法）
  safety.py      关键词 / 外链隔离 / 拉黑策略（不访问链接）
  models.py      chat / vision / search / image（OpenAI 兼容 + 备用回退）
  scheduler.py   主动行为（刷视频/评论/动态/私信轮询）
adapters/      平台适配器（只管“怎么说话”，不管“说什么”）
  base.py        统一接口：poll() / send() / capabilities()
  bilibili.py    评论·私信·动态·直播·视频（★ 底层换成 bilibili-api-python）
  qq.py          NapCat/OneBot（我们现有的 ✓ 直接包过来）
prompts/       可编辑提示词（人格/主动评论/视频评价/性格演化/搜索/动态/画图）
data/          运行时（记忆/好感/日志）
config.json    热更新配置（照它那套 ✓）
```

## 从那个库拿过来的东西（我们现在没有的 ✗）

| 能力 | 现状 | 拿过来后 |
|---|---|---|
| 语义向量记忆（bge-m3） | 只有关键字笔记 ✗ | 按线程/用户检索 ✓ 自动压缩 ✓ 永久记忆 ✓ |
| 好感度 + 关系等级 | 没有 ✗ | 陌生人→粉丝→熟人→好友→主人 ✓ 态度随之变 |
| 心情系统 | 没有 ✗ | 实时心情影响语气 ✓ |
| 性格成长（每日反思） | 没有 ✗ | 特质/口癖/看法随时间演化 ✓ |
| **Cookie 自动刷新**（refresh_token + RSA 5 步） | 没有 ✗ **今天 csrf 缺失就是这个病** | 全自动 ✓ |
| 私信安全（外链隔离/信任域名/自动拉黑） | 只有关键词过滤 ✗ | 隔离不送 LLM ✓ 可拉黑 ✓ |
| 可视化面板（成长/成本/活动日志） | 有一半 ✗ | 全部 ✓ |
| AI 画图 + 动态配图 | 没有 ✗ | ✓ |
